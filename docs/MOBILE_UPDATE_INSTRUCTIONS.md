## Команды для обновления на сервере:

```bash
# 1. Перейти в директорию проекта
cd /root/the-sim-final

# 2. Получить последние изменения
git pull origin main

# 3. Остановить контейнеры
docker-compose -f docker-compose.prod.yml down

# 4. Пересобрать и запустить
docker-compose -f docker-compose.prod.yml up --build -d

# 5. Проверить статус
docker-compose -f docker-compose.prod.yml ps

# 6. Проверить логи при необходимости
docker-compose -f docker-compose.prod.yml logs app
```

## Поддержка:

Если возникнут проблемы:
1. Проверьте логи: `docker-compose -f docker-compose.prod.yml logs`
2. Перезапустите: `docker-compose -f docker-compose.prod.yml restart`
3. В крайнем случае пересоберите: `docker-compose -f docker-compose.prod.yml up --build -d`
