# 🔧 Исправление ошибки сборки

## Проблема:
Ошибка `Cannot find module 'tailwindcss'` возникает потому что использовался `npm install --production`, который не устанавливает dev зависимости, необходимые для сборки.

## Решение:

### На сервере выполните:

```bash
# 1. Установить ВСЕ зависимости (включая dev)
npm install

# 2. Пересобрать проект
npm run build

# 3. Перезапустить PM2
pm2 restart thesim

# 4. Проверить логи
pm2 logs thesim --lines 30
```

---

## Полная последовательность команд:

```bash
cd /root/the-sim-final

# Установить все зависимости (включая dev для сборки)
npm install

# Пересобрать проект
npm run build

# Перезапустить PM2
pm2 restart thesim

# Проверить статус
pm2 status

# Проверить логи
pm2 logs thesim --lines 50

# Проверить что сайт работает
curl -I https://thesim.site
```

---

## Почему нужны dev зависимости?

Next.js требует dev зависимости для сборки:
- `tailwindcss` - для стилей
- `postcss` - для обработки CSS
- `typescript` - для компиляции TypeScript
- и другие инструменты сборки

После сборки эти зависимости не нужны для запуска, но они необходимы для процесса сборки.

---

## Альтернативный вариант (если нужно экономить место):

```bash
# Установить все зависимости
npm install

# Пересобрать
npm run build

# Удалить dev зависимости после сборки (опционально)
npm prune --production

# Перезапустить PM2
pm2 restart thesim
```

Но лучше оставить все зависимости, так как при следующем обновлении они все равно понадобятся для сборки.
