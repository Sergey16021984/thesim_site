# 🌐 DNS настройка для thesim.site

## 📋 DNS ЗАПИСИ (настройте в панели домена):

### Основные записи:
```
Тип    Имя    Значение                    TTL
A      @      YOUR_SERVER_IP              300
A      www    YOUR_SERVER_IP              300
CNAME  api    thesim.site                 300
CNAME  admin  thesim.site                 300
```

### Дополнительные записи (опционально):
```
Тип    Имя    Значение                    TTL
TXT    @      "v=spf1 include:_spf.google.com ~all"  300
CNAME  mail   ghs.google.com              300
```

## 🔧 ГДЕ НАСТРОИТЬ:

### 1. В панели управления доменом:
- Войдите в панель управления доменом
- Найдите раздел "DNS" или "Управление DNS"
- Добавьте записи выше

### 2. Популярные регистраторы:
- **Reg.ru**: Панель управления → DNS
- **GoDaddy**: DNS Management
- **Namecheap**: Advanced DNS
- **Cloudflare**: DNS → Records

## ⏱️ ВРЕМЯ ПРИМЕНЕНИЯ:
- **A записи**: 5-15 минут
- **CNAME записи**: 5-30 минут
- **Полное распространение**: до 24 часов

## ✅ ПРОВЕРКА DNS:
```bash
# Проверка A записи
nslookup thesim.site
nslookup www.thesim.site

# Проверка CNAME
nslookup api.thesim.site
nslookup admin.thesim.site
```

## 🚀 ПОСЛЕ НАСТРОЙКИ DNS:

1. **Подождите 15-30 минут**
2. **Проверьте DNS**: `nslookup thesim.site`
3. **Разверните код на сервере**
4. **Настройте SSL сертификат**
5. **Проверьте работу сайта**
