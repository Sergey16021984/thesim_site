# 🔧 Настройка браузера для разработки

## Проблема
Ошибки в консоли от расширений браузера (Adblock, Torrent Scanner и др.)

## Решение 1: Режим инкогнито
1. Откройте Chrome в режиме инкогнито (Ctrl+Shift+N)
2. Перейдите на `http://localhost:3000/ru`
3. Ошибки от расширений не будут появляться

## Решение 2: Отключение расширений
1. Откройте `chrome://extensions/`
2. Отключите все расширения кроме необходимых
3. Перезагрузите страницу

## Решение 3: Создание профиля разработчика
1. Откройте `chrome://settings/`
2. Перейдите в "Люди" → "Добавить человека"
3. Создайте профиль "Разработка"
4. В этом профиле не устанавливайте расширения

## Решение 4: Использование другого браузера
- Firefox Developer Edition
- Edge (без расширений)
- Safari (на Mac)

2. Откройте DevTools (F12)
3. Консоль должна быть чистой
4. Форма должна работать без ошибок
