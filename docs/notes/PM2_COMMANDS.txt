===========================================
КОМАНДЫ ДЛЯ ОБНОВЛЕНИЯ ЧЕРЕЗ PM2
===========================================

1. Обновить код из GitHub:
   cd /root/the-sim-final
   git pull origin main

2. Обновить зависимости:
   npm install --production

3. Пересобрать проект:
   npm run build

4. Перезапустить PM2:
   pm2 restart thesim
   # или если имя другое:
   pm2 restart all

5. Проверить статус:
   pm2 status
   pm2 logs thesim --lines 30

===========================================
БЫСТРАЯ КОМАНДА (все в одном):
===========================================

cd /root/the-sim-final && \
git pull origin main && \
npm install --production && \
npm run build && \
pm2 restart thesim && \
pm2 logs thesim --lines 20

===========================================
ПРОВЕРКА РАБОТОСПОСОБНОСТИ:
===========================================

# Проверить статус PM2
pm2 status

# Проверить логи
pm2 logs thesim --lines 50

# Проверить что сайт работает
curl -I https://thesim.site

# Мониторинг в реальном времени
pm2 monit

===========================================
ЕСЛИ PM2 НЕ ЗАПУЩЕН:
===========================================

# Проверить список процессов
pm2 list

# Если приложение не найдено, запустить заново:
cd /root/the-sim-final
npm run build
pm2 start npm --name "thesim" -- start
pm2 save

# Настроить автозапуск при перезагрузке:
pm2 startup
# Выполните команду, которую выведет PM2

===========================================
ЕСЛИ ПОРТ 3000 ЗАНЯТ:
===========================================

# Найти процесс
sudo lsof -i :3000

# Остановить PM2
pm2 stop all
pm2 delete all

# Убить процессы Node.js
sudo killall -9 node

# Запустить заново
pm2 start npm --name "thesim" -- start

===========================================
ВАЖНО: ОБНОВИТЬ СЕКРЕТЫ В .env
===========================================

nano .env

# Обновить:
