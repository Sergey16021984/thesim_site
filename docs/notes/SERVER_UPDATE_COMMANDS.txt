===========================================
КОМАНДЫ ДЛЯ ОБНОВЛЕНИЯ НА СЕРВЕРЕ
===========================================

После того как вы отправите изменения в GitHub локально,
выполните эти команды на сервере:

1. Перейти в директорию проекта:
   cd /root/the-sim-final

2. Получить обновления из GitHub:
   git pull origin main

3. Проверить что обновилось:
   git log -1 --oneline

4. Перезапустить Docker контейнеры:
   docker-compose restart

5. Проверить логи (убедиться что все работает):
   docker-compose logs -f --tail=50

6. Проверить что сайт работает:
   curl -I https://thesim.site

===========================================
ВАЖНО: Обновить секреты в .env файле!
===========================================

После обновления кода обязательно обновите секреты:

1. Отредактировать .env файл:
   nano .env

2. Обновить следующие значения:
   - TELEGRAM_BOT_TOKEN (если был скомпрометирован)
   - TELEGRAM_CHAT_ID
   - TELEGRAM_CHAT_ID_2 (если используется)
   - JWT_SECRET
   - ENCRYPTION_KEY
   - COOKIE_SECRET
   - CSRF_SECRET

3. После обновления перезапустить:
   docker-compose restart

===========================================
Проверка SSL сертификатов (опционально)
===========================================

1. Проверить срок действия:
   sudo certbot certificates

2. Обновить если нужно:
   sudo certbot renew
   sudo systemctl reload nginx

3. Сгенерировать dhparam (если еще не создан):
   sudo openssl dhparam -out /etc/nginx/dhparam.pem 2048
   sudo chmod 600 /etc/nginx/dhparam.pem
   sudo systemctl reload nginx
